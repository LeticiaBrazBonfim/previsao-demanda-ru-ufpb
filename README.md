# Projeto Aplicado: Previsão de Demanda do Restaurante Universitário (RU - UFPB)

## Visão Geral
Este projeto tem como objetivo estimar o consumo por refeição, em reais por dia e por curso no Restaurante Universitário (RU) da UFPB para os estudantes das Escolas Técnicas, apoiando a alocação de subsídios e planejamento operacional.

Devido à ausência de liberação dos dados institucionais pelos demandantes dentro do prazo, o projeto encontra-se estruturado em nível conceitual, arquitetural e documental, aguardando o recebimento das bases reais (catraca e registros acadêmicos) para a execução quantitativa do pipeline e dos modelos.

## Estrutura do Repositório
- `dados/bruto/`: Repositório destinado aos dados originais da instituição.
- `dados/processado/`: Base analítica limpa, transformada e pronta para modelagem.
- `notebooks/`: Análises exploratórias, auditorias e validação de baselines.
- `src/`: Scripts Python reutilizáveis para pré-processamento e pipelines.
- `docs/`: Canvas de ML, memórias de escuta, especificações técnicas e guia de ambiente virtual.
